# ReqAI — MVP Backlog

## EPIC 01 — Project Management

### US-001 — Criar Projeto

**Como** usuário
**Desejo** criar um projeto
**Com o objetivo de** fornecer contexto para as análises de requisitos.

### US-002 — Visualizar Projetos

**Como** usuário
**Desejo** visualizar meus projetos
**Com o objetivo de** acessar e continuar o trabalho de cada produto.

## EPIC 02 — Requirements

### US-003 — Registrar Requisito

**Como** usuário
**Desejo** registrar uma demanda em linguagem natural
**Com o objetivo de** submetê-la à análise da IA.

### US-004 — Visualizar Requisito

**Como** usuário
**Desejo** visualizar o requisito e seus artefatos
**Com o objetivo de** revisar o resultado da análise.

## EPIC 03 — AI Generation

### US-005 — Gerar User Story

**Como** usuário
**Desejo** gerar uma User Story com IA
**Com o objetivo de** transformar uma demanda informal em uma especificação estruturada.

### US-006 — Gerar Critérios de Aceitação

**Como** usuário
**Desejo** gerar critérios de aceitação com IA
**Com o objetivo de** tornar o requisito verificável.

### US-007 — Gerar Regras de Negócio

**Como** usuário
**Desejo** identificar regras de negócio com IA
**Com o objetivo de** explicitar condições necessárias à implementação.

## EPIC 04 — Quality Analysis

### US-008 — Analisar Qualidade do Requisito

**Como** usuário
**Desejo** analisar a qualidade do requisito com IA
**Com o objetivo de** identificar problemas antes do desenvolvimento.

### US-009 — Visualizar Pendências

**Como** usuário
**Desejo** visualizar perguntas e informações ausentes
**Com o objetivo de** esclarecer o requisito antes da implementação.

## EPIC 05 — Versioning

### US-010 — Editar Resultado da IA

**Como** usuário
**Desejo** editar o conteúdo gerado pela IA
**Com o objetivo de** ajustar a especificação à decisão do negócio.

### US-011 — Versionar Requisito

**Como** usuário
**Desejo** salvar versões do requisito
**Com o objetivo de** manter rastreabilidade das alterações.
