# ReqAI — Portfólio

## Elevator pitch

ReqAI is an AI-powered requirements engineering workspace that transforms raw business demands into structured, reviewable requirements artifacts.

## What the project demonstrates

- Requirements engineering
- Product management thinking
- Clean Architecture
- Spring Boot API design
- PostgreSQL persistence
- PostgreSQL + pgvector RAG architecture
- Multi-provider AI Gateway
- BYOK credential architecture
- Structured AI outputs
- Model evaluation and routing
- Docker and CI/CD
- Modern SaaS frontend

## AI differentiator

The platform is intentionally provider-neutral and evaluates global and Chinese AI models through the same requirements-engineering benchmark. Candidate providers include DeepSeek, Qwen, GLM, ERNIE, OpenAI, Gemini and Anthropic.

## Demonstration scenario

1. Create a project.
2. Register a raw requirement.
3. Run AI analysis.
4. Review the generated User Story.
5. Review acceptance criteria and business rules.
6. Resolve clarification questions.
7. Inspect quality findings and score.
8. Compare providers/models.
9. Approve the requirement baseline.

## Portfolio message

The objective is not to demonstrate a chatbot. The objective is to demonstrate a production-oriented product that applies AI to a real software-engineering workflow with traceability, governance, measurable quality, and provider flexibility.
