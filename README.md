# ReqAI

> AI-powered platform for requirements engineering.

ReqAI is a portfolio-grade product designed to transform informal business demands into structured software requirements and proactively identify requirement quality issues.

## Vision

Help product and engineering teams turn conversations, documents, and informal requests into clear, testable, traceable requirements with the support of AI.

## Core capabilities

- Generate User Stories from natural-language demands
- Generate Acceptance Criteria and Business Rules
- Analyze requirements for ambiguity, inconsistency, incompleteness, and duplication
- Suggest missing questions and decisions
- Maintain project context and requirement history
- Evolve toward RAG and AI Agents for impact analysis

## Product roadmap

### MVP

1. Project creation
2. Requirement input
3. AI User Story generation
4. Acceptance Criteria generation
5. Business Rule generation
6. Requirement quality analysis
7. Analysis history

### Evolution

- Document ingestion
- RAG with PostgreSQL + pgvector
- Impact analysis
- BDD generation
- BPMN generation
- GitHub / Azure DevOps / Jira integrations
- AI Agent for requirements engineering

## Planned stack

- Frontend: Next.js + TypeScript
- UI: Tailwind CSS + shadcn/ui
- Backend: Java + Spring Boot
- Database: PostgreSQL
- Vector search: pgvector
- AI: LLM API
- Tests: JUnit, Testcontainers, Playwright
- Infrastructure: Docker
- CI/CD: GitHub Actions
